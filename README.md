# BTC Liquidity Scanner

Android application for monitoring Binance Spot BTC/USDT order book liquidity.

## Stage 1

- Kotlin
- Jetpack Compose
- Binance Spot public API
- BTC/USDT order book
- Automatic refresh every 5 seconds
- GitHub Actions APK build

The application does not require a Binance API key for the public order book endpoint.
